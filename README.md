# Pages légales de Peps : déménagées

Depuis le 1er novembre 2026, la politique de confidentialité, les conditions d'utilisation et le support de Peps (anciennement NUTRI AI) sont publiés sur **https://pepsmacros.com** (hébergement OVH), à la demande de Mathys.

Les pages de ce dépôt ne contiennent plus que des renvois vers le nouveau site, pour que les anciens liens (builds de test de l'app) continuent de marcher. Le texte en vigueur et son historique sont dans `~/Desktop/pepsmacros-site/` sur le Mac.
